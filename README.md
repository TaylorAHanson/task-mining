# task-mining

Exploration toward a Databricks-native field asset for end-to-end **process discovery and automation**: finding manual work wherever an enterprise leaves traces of it, and replacing it with Databricks-native automations.

Planning is tracked as a wayfinder map in this repo's issues (label `wayfinder:map`). Vocabulary lives in [GLOSSARY.md](./GLOSSARY.md).

**This repo is public.** No secrets, credentials, workspace URLs, or customer names or data — ever. All examples use a fictional reference enterprise and synthetic data.
